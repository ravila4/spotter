# Training load

[Foster's session-RPE method](../sources/foster-2001-monitoring-exercise-training.md)
combines one whole-session effort rating with duration. It provides a way to
describe internal load consistently over time. It does not measure calories or
predict an injury.

`session_load_AU = session_RPE × duration_minutes`

The source note records the modified 0–10 scale, collection timing, studied
populations, and page citations. A weekly sum is meaningful only with consistent
duration definitions and visible missing sessions. Missing ratings are not rest
days.

## Different measures describe different things

| Measure | What it describes | Required data |
| --- | --- | --- |
| Session-RPE load | Perceived whole-session effort combined with time | Explicit numerical session rating and minutes |
| Strength volume-load | External load multiplied by repetitions | Comparable equipment, complete loads/reps and consistent units |
| Time in intensity zones | Distribution of time under a chosen intensity definition | Zone boundaries, their basis, and duration within each zone |

These values cannot be substituted for one another. The
[strength source note](../sources/haff-triplett-essentials-strength-conditioning-4ed.md)
defines volume-load; the [running topic](running.md) covers zone interpretation.

Spotter currently keeps effort in the user's words for each set. That should
remain intact. A future session-RPE field would collect a separate observation,
not a conversion of those descriptions. Neither this collection nor the current
schema supplies a validated Body Battery cutoff for choosing session intensity.

Monotony and strain are mentioned in Foster's paper but remain unextracted:
the scanned examples need visual verification before reuse. No injury alarm
threshold is adopted here.
