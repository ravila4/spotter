# Training knowledge wiki

An on-demand reference for training questions. Start with a topic, then follow
its source notes for numerical details, limitations, and page citations. The
[source inventory](../resources/README.md) lists the original documents.

| Directory | Contents |
| --- | --- |
| `sources/` | One note per source, with page citations, findings, formulas, and limitations |
| `topics/` | Summaries across sources, linked to the supporting source notes |

Keep formulas with input definitions, units, and assumptions. Distinguish study
results from recommendations, and record the population and context for numerical
ranges. Record both printed and PDF page numbers when they differ. Link to source
documents using repository-relative paths and include a DOI or publisher URL
when available.

## Coverage and use

This is a selected extraction, not a systematic review of all current research.
Each note records its coverage. The textbooks are indexed selectively; the
unrelated Garthe paper and empty Zatsiorsky file are excluded. Newer evidence is
identified where checked, without implying that every source has been updated.

The local PDFs are ignored by Git and will not accompany a clone. Public links
in the source notes identify the works; access may require a library or purchase.
Summaries use original wording and do not reproduce textbook tables or programs.

The wiki is reference material. Reading a paper does not authorize a change to
the database, training goals, or Garmin account. A recommendation still needs
the user's context and the inputs named by the source note.
