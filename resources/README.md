# Research resources

Original PDFs live in `sources/`, which is ignored by Git. Preserve their contents;
use descriptive filenames with an author or organization, verified year when
available, and a short title. Full source documents are separate from the
repository's MIT-licensed code.

Source notes and topic summaries belong in [the wiki](../wiki/README.md).
